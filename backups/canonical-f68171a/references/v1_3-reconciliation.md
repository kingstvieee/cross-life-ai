# STAARWARDD v1.3 Directive Reconciliation

The v1.3 update is an **experience rebuild inside the existing native mobile project**. It preserves the seven stable portal IDs, existing routes, native package configuration, planning/approval boundary, integration state, approved Hub cover artwork, and existing data structures. No live connection, account, device, health, location, calendar, wearable, shopping, or relationship claim may be added unless the existing application has the required data and authorization.

## Authorized implementation scope

The update authorizes an original Guardian-led cinematic opening; short original portal-entry motion; a shared, optional audio-control surface; a non-plain atmospheric Hub; immersive portal interiors; context-adaptive Guardian copy and text-to-speech; Events interest setup and local status actions; and an original Guardian-derived app icon. All primary experiences must retain readable content, reduced-motion behavior, performance fallbacks, and existing approval boundaries.

The existing seven cover bindings remain unchanged: Creativity, Work, Home, Wellbeing, Relationships, Events, and Style. The Events cover is still bound to the approved legacy source file `portal-community-v7.webp`, as already mapped to the canonical `events` ID.

## Verified asset boundary

The project currently contains an approved Guardian illustration, maple sigil, seven portal cover files, and existing summoning visual assets. It does **not** contain approved Kaia imagery, Atlas imagery, a STAARWARDD watch image, or separate approved fashion reference imagery. The directive prohibits random/generated replacements for Kaia, Atlas, and the watch, so those visual slots remain explicitly unavailable until the approved files are supplied. No claim of companion-device capability or connection will be introduced.

Visual review confirms the Guardian source is a project-owned celestial Toronto character illustration with a strong face, armor, wings, and gold-light identity. The existing summoning-bubble asset is an abstract blue-and-gold dimensional ring and is appropriate for original portal materialization layers. Neither asset is used to alter any approved portal cover image.

## Trust and media boundary

Text interaction remains local preview behavior. Guardian spoken responses use the device’s text-to-speech capability only when a user enables voice; this is not a claim of live conversational AI or voice transcription. Music and ambience remain off by default and require explicit user control. No automatic loud audio, fake live event availability, fabricated home/wellness state, or unapproved external action is permitted.
