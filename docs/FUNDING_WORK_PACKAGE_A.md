# STAARWAARDD Work Package A - Guardian Context + Action Engine

**Application starter pack | Toronto, Ontario | October 1, 2026**

## Research abstract
STAARWAARDD is developing a Canadian whole-life AI coordination environment built around one Guardian, seven bounded life domains, a provenance-aware context graph and a permissioned action control plane. This R&D project focuses on the Guardian Context + Action Engine, the layer responsible for retrieving only relevant context, resolving cross-domain conflicts, classifying action risk, requesting approval where required, executing permitted tools, verifying results and producing user-visible action receipts.

The research challenge is not generic AI assistance. It is reliable coordination across heterogeneous personal and operational domains while preserving privacy boundaries, context provenance, user control and auditability. The pilot will implement a provenance-aware context schema, cross-domain task graph, risk/approval tiers, controlled tool gateway, verification layer and evaluation harness for task success, context precision, approval accuracy, latency, cost and failure recovery.

## Technical uncertainty
- Minimum-sufficient cross-domain retrieval without leaking unrelated sensitive information.
- Representation of dependencies and conflicts across Work, Home, Wellbeing, Relationships, Community, Creativity and Style.
- Consistent risk classification for read-only, draft, reversible and consequential actions.
- Execution verification plus evidence receipts and rollback information where available.
- Acceptable latency and model cost through model routing and bounded context.

## Hypothesis
A dedicated coordination and policy layer, separate from the generative model, can improve cross-domain task success and user control while reducing unnecessary context exposure and premium-model usage.

## 4-6 month milestones

2. Cross-domain task graph.
3. Guardian risk + approval engine.
4. Tool gateway + action receipts.
5. Evaluation harness.
